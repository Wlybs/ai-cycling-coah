# Allen-Coggan FTP test protocols

**Setting.** Cycling-specific FTP estimation protocols used as the basis of zone derivation in TrainingPeaks, Intervals.icu, and most power-based training systems.

**Key finding.** The 20-min × 0.95 protocol approximates Critical Power for trained cyclists within ±5%. The CP-WR (CP, W' reconstruction) framework is more accurate but requires ≥3 maximal efforts at different durations (e.g., 3 min, 8 min, 20 min) — only worth the testing burden when fitness is changing rapidly.

**Fast-twitch caveat.** The 8-min ramp test consistently **underestimates** FTP for fast-twitch dominant riders by 5-10%. This is because the ramp protocol's terminal power is partially anaerobic; fast-twitch riders fade slower in the final minute due to higher W' contribution, but the shape of the test still rewards aerobic capacity over short max output. Use 20-min × 0.95 for this athlete profile.

**Calibration cadence.**
- Build phase: every 6-8 weeks
- Peak phase: not required (use race-day power as the indicator)
- Off-season: not required (FTP drift expected, re-test on entry to base)

**For this athlete.** With Type II fast-twitch dominance, prefer 20-min protocol; expect the test to feel "soft" in the first 5 min and brutal in the last 5 — the negative split is desirable.

**How Coach should use this.** When CTL is climbing steadily and last FTP test is >7 weeks old, suggest a re-test; cite this card. If the user's existing FTP came from an 8-min ramp, flag possible underestimation by ~7% for this profile.
