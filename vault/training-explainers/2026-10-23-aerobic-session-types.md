# 有氧课三分类（恢复 / LSD / 耐力）：抖音科普核查

## 来源
- 抖音「砖头哥（王子一）」2026-10-22 发布，1:40。内容取自视频字幕与白板原文，不用页面「AI生成」章节摘要。
- 白板顶部写「定制训练课 199元/8周」：带引流性质，内容定位入门科普。

## 视频主张（原文要点）
| 项目 | 恢复课 | LSD课 | 耐力课 |
|---|---|---|---|
| 目的 | 主动恢复 | 打基础、提升有氧代谢 | 长时间稳定输出，重点在输出 |
| 区间 | 1–2区交界 | 2区，更贴近1区的2区 | 2区，有时贴近3区；可混入3区、最大摄氧量、冲刺 |
| 时长 | 45–60min；职业90–120min | 2.5–3h；职业更长 | 1.5–2h |
| 频次 | 每次大强度或比赛后 | 至少每周一次 | 建议每周两次 |
| 补给 | 不需要 | 一定要有 | 一定要有，有无补给表现差别很大 |

评论区作者回复网友：「60–70%吧或者可以放宽到75%上下，别超过75」。网友提问用的是最大心率（220−年龄）；本人 10/23 指出作者百分比指功率（%FTP），以本人解读为准。

## 判定
| 主张 | 判定 | 依据 / 边界 |
|---|---|---|
| 三类按目的区分 | 同意 | 教练实践分类，不是研究定义 |
| 强度（按 %FTP 理解） | 同意 | 60–75% FTP 落在 Coggan 功率分区 Z2（56–75%，行业约定，非试验结论）。本人 LSD 180–200W ≈ 工作 FTP 300W 的 60–67%。%FTP 准度取决于 FTP；本人 300W 是工作设置非实测 |
| 若读成 %最大心率 + 220−年龄 | 不采用 | Ausland, Kelemen & Seiler 2026（Front Sports Act Living, doi 10.3389/fspor.2026.1806303）：4375 名耐力运动员，Fox(220−年龄) 平均低估自报 HRmax 5.8 bpm，95% 一致性界限 −20.2~+8.6 bpm；HRmax 为自报值 |
| 时长、频次 | 存疑（经验值） | 未找到直接试验；与本人现有安排（LSD 3.5–4h、每周最多两次 3.5h+）不冲突 |
| 每次硬课后都要恢复课 | 不同意作硬规则 | 本轮未找到近三年比较「次日主动恢复 vs 全休」的综述。本人 5/11 规则：全休或 ≥60min Z2 |
| 恢复课不需补给 | 大体同意，措辞过头 | Jeukendrup 等 2026, IJSNEM 36:215–232, doi 10.1123/ijsnem.2025-0239，Table 2 示例：1-hr easy spin 0–30 g/hr；即可吃可不吃，不是「肯定不需要」 |
| LSD / 耐力课要补给 | 同意 | 同上 Table 2：3-hr endurance training 60 g/hr。本人纯有氧 45–60 g/h 实践接近 |

## 对本人的应用（教练判断）
- 不用 220−年龄或 %最大心率定区间；强度沿用功率锚点（见 [[athlete-quick-facts]] 数据解读口径）。
- 不为 CTL / 周 TSS 数字加恢复课。算例：45min、IF 0.55 → TSS ≈ 0.75×0.55²×100 ≈ 23；每周一次，CTL 长期约 +3（23/7）。周时长不足时把时间加到已有 Z2 骑行或单独 ≥60–90min Z2。通勤、社交骑照骑，不计为训练任务。5/11 规则保留。
- 本笔记不改 FTP、区间设定、课表或 ICU 日历。
