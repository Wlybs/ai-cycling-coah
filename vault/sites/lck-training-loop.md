# LCK（Lim Chu Kang）训练圈

## 适用范围
用户10/17明确偏好threshold等较长训练在LCK执行。路线来自本人8–10月活动与关联Strava段，不是泛用新加坡旅游路线。本人10/17进一步确认：常规几乎不用考虑红绿灯，主要考虑U-turn。按该现场知识组织，不把不明低速片段当常规红灯障碍。

## 场地轮廓
- 完整圈例39567443 Tour De LCK：10/16两圈13.61/13.60km、22:20/21:52（228/229W）；海拔记录约11–25m，250m平滑累计上升42/43m。是平缓起伏的南北往返圈。
- 同日40192048 New LCK Loop x3约41.37km/68:55，是三圈，不是一圈41km。
- 北向39332531约6.86km，过去约9–12min；9/11一趟9:43均301W是训练观察，不是本人确认的全力FTP测试。南向39359016约5.26km，另有接驳/转向区；不能把两个不同时起终点片段长度直接当完整圈。
- 北端方向反转约在某代表圈6.8km附近；配套图横轴从该记录映射起点算，不是路面里程牌。4–5km与8–10km附近轻微起伏可以练稳定瓦数，不必每个小包都attack。没有测绘级高程；本人常规执行重点是U-turn。

## 课型适配
1. 北向单程3趟@280–290W，按9–12min实际量级，南向返回恢复，累计27–36min；恢复较长是地形折中，不称连续30min。
2. 2×20min受控后再进2×25min，可跨圈；以计时工作量为准，U-turn减速后平顺恢复目标功率，不补冲刺、不重置计时，不强求一圈恰20min。
3. 有氧/长骑也适合在此重复，但路速不能直接比较训练水平；风、跟车、路况显著干扰。
4. 整次至少2h，额外部分是有氧与往返；常规按U-turn短暂降功执行，不因此要求转骑台；异常中断则如实记录。受控持续280–290W基于当前300W工作设置，不是新的LT2测量，后续数字以实时snapshot及完成质量校准。
