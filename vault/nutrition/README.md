- [[nutrition/foods]] 保存常吃食品的品牌、版本、每100g营养、来源和确认状态。

- 估算与标签值分开；普通食物说明生熟、可食重量和假设。未查到的微量营养不填0。
- 没有当前消耗/体重趋势时，不凭摄入单独判热量盈余或缺口；不把一天数据判成增脂/减脂结果。
