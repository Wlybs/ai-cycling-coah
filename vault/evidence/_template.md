# 研究卡片模板与规则

> 本目录是教练讲训练原理时的**可核依据库**（[研究] 档）。一条结论一张卡，文件名 `<ULID>.md`。
> 格式与 `icu/evidence_corpus/` 同构：`CorpusReader` 与 `scripts/evidence_lint.py --corpus ../vault/evidence` 可直接读取；`_` 开头的文件（本模板、`_index.md`、检索日志）读取器会跳过。
> 卡片正文用中文；`tags` 用英文 snake_case（检索器只认英文词）。

## 硬规则

1. 每个数字都写原文位置：全文卡写到节、表、图（如「Results §3.2」「Table 2」「Fig. 3」）；只读到摘要的写「摘要」，并在 `read_level` 标「摘要级」。
2. 原文没有的内容不写；自己的推断标［推断］，自己的换算标［换算］并写出算式。标签不能代替来源。
3. 不写本人的具体数字（FTP、体重、CP 等）；需要时写「读 coach_memory/athlete_snapshot.json」。
4. 引用原文原句每处不超过 15 个英文词，其余用自己的话。
5. 研究间有冲突，两边都写，并在「与其他卡片的关系」互相链接。

## 证据强度（evidence_level）

| 档 | 含义 |
|---|---|
| 强 | 系统综述、meta 分析或共识声明，且与近三年研究一致 |
| 中 | 方法比较、对照或交叉设计的原始研究，样本量尚可（约 15 人以上）；或方法有明显局限的系统综述 |
| 弱 | 小样本（约 15 人以下）、单个观察性研究、叙述性综述中的观点 |
| 专家意见 | 书、教练文章、平台文档：出处可核，但没有给出数据 |
| 无来源 | 查不到任何可核出处 |

## 说法核查卡（card_kind = "claim_check"）

用于核对教练或社区流传的说法。`authors = ["本项目说法核查"]`，`year` 为核查年份，`source` 写「说法核查卡，出处见正文」。

```
# 说法核查：<说法原文>

## 说法
## 判定
（无来源 / 有出处但无研究支持 / 部分成立需改写 / 被推翻，一句话理由）
## 出处追查
（作者、标题、年份、URL、该来源写的数字、该来源给出的依据；只写本轮亲自打开核对过的）
## 研究证据
（引用研究结论卡的 ULID，各一句话）
## 教练以后应该怎么说
## 核查记录
```
