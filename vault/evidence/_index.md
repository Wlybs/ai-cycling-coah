# 研究卡片库目录

> 用途：教练讲训练原理、生理换算、阈值或分界线时的**可核依据库**（[研究] 档）。一条结论一张卡；先看本目录，再打开具体卡片。
> 格式与规则：[[evidence/_template]]。证据强度分五档：强 / 中 / 弱 / 专家意见 / 无来源。「读到」为摘要级的卡只核到摘要。
> 本目录由脚本按卡片 TOML 头生成；改卡后重新生成，不要手改表格。

## 使用规则（给教练）

1. 讲原理先查本目录。引用时写卡片编号与作者年份，例如「（F03，Inglis 2020）」；数字以卡片「数字与原文位置」表为准。
2. 卡片里没有的，就直说“证据库里没有这条的来源”；可以给教练判断，但标［教练判断］，不拿它计算、不拿它反推。
3. 「说法核查」判为无来源或无研究支持的说法，不得再当规律使用（见文末“无来源清单”）。
4. 摘要级的卡，引用时说明“摘要级”。

## 无来源清单（不得再当规律使用）

- 「4 小时稳态 ≈ FTP 的 70–78%」：研究和教练资料都没有（C01）。
- 「阈值间歇 ≈ FTP 的 93–105%」以及用间歇功率反推 FTP：区间无出处，反推无依据（C02）。
- 「脱钩 5% 是生理分界线」：5% 是 Friel 的经验线，没有研究支持（C03）。
- 「肠道葡萄糖吸收上限 60 g/h」这一表述：60 g/h 是单一碳水外源氧化的近似上限，吸收饱和是推测机制（C04）。
