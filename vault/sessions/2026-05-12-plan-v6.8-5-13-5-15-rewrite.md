## 5/15 race-rhythm 第 1 set 6min 判官规则

按真实课表（6min 含 3 次 W' burst）调整后的现场判定：

| 第 1 set 6min 体感 | 决策 |
|---|---|
| 3 次冲刺都到 450W、稳态守住 330W、RPE 8 | **正常**，完成 3 set 全套 |
| 第 1 set 第 3 次冲刺只到 420W | 完成 3 set 但**第 3 set 末次冲刺可降到 400W** |
| 第 1 set 整体功率守不住、稳态跌到 310W | **砍 2 set 不要硬撑** |
| 第 1 set 3 次冲刺都到 460W+、稳态 RPE 7 | 按 3 set 原计划做完，**不要加 4 set** |

**坚决不加 4 set**（之前建议撤回，混合课加组反向风险高）。
