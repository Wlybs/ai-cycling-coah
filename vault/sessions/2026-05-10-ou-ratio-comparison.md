# 2026-05-10 ｜ OU 比例对比：1/1 vs 1.5/1.5 vs 2/1

## 用户原始请求

> 那如果1：1的比例改成每一组1.5min可以吗？或者2min/1min？和现在这个训练计划相比怎么样

## 数据快照（使用的证据）

- FTP=300W, CP=300W, W' 真池 22-25kJ + AWC 10-12kJ = 总池 35-36kJ
- 当前 1/1: 330W/270W, 5 cycles × 2min = 10min set, 4 set
- Mountain 2 climb time = 10-11min（set 时长上限）
- race 中段拉锯 attack = 25-30s 不是 2min

## sync 警告

无（方法论问题，物理核算依赖已锁定的 anchor 数）

## 教练判定

物理核算结果：

| 方案 | over W'/cycle | set 时长 | 4 set 总 W' | climb 匹配 | 刺激 |
|---|---|---|---|---|---|
| 1/1 当前 | 1.8 kJ | 10min | ~22 kJ | ✅ | Lactate clearance ⭐ |
| 1.5/1.5 | 2.7 kJ | 12min | ~27 kJ | ❌ 超 climb | LC → VO2max 边缘 |
| 2/1 | 3.6 kJ | 10min (3+1) | 32-35 kJ | ✅ 但是 | VO2max + W' burner |

**1.5/1.5 三个问题**：
1. 12min set 超 Mountain 2 climb，破坏"一爬=一拉锯"race-specific
2. 1.5min @ 110% 进入 VO2max 响应窗（60-90s），刺激偏移
3. 27kJ 净消耗逼近真 W' 25kJ 上限，4th set 衰减概率高

**2/1 等于 VO2max session 不是 OU**：
1. 文献里 2:1 work:rest 是 Coggan VO2max 间歇范畴
2. 32-35kJ 净消耗 = 总池 35-36kJ 上限，必爆
3. race-specific 不对应（race attack 是 25-30s 不是 2min）

## 处方

- **5/10 维持 1/1 不改比例**
- 增加刺激的优先级：set 数 4→5 > 强度 110%→112% > 改比例
- "想试 1.5/1.5"的折中：临时把第 1 组改 1.5/1.5 测身体反应，其余 3 组 1/1，不全替换

## 触发器

- 5/10 4 set 完成度判断：
  - 第 4 组 over 衰减 <310W → 下次回 105/95 或减到 3 set，不是改比例
  - 第 4 set 完成有余量 → 下次升 112/88 而非 1.5/1.5
- 5/13 Mountain 1 B race-rhythm 完成度 → 决定 6 月块是否需要把 1/1 OU 升级
- 5/17 race 后中段拉锯感受 → 验证 1/1 lactate clearance 剂量是否够
