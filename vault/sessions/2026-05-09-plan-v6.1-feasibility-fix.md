# 2026-05-09 ｜ Plan v6.1 — W'/CP 物理可行性核算 + 5/10 现实版

## 用户原始质疑

> "5.10 这个课程你真的觉得我能骑下来吗？差不多相对于 4x8min 的变种高强度的 vo2max，强度有点可怕了吧。你是否考虑过客观实际，还是说你能用理论证明我能骑完？"

## 我的失误（v6 设计）

5/10 race-rhythm 4 set × 4 cycles × (90s @ 330W + 30s @ 500W) — 听起来合理，但**没做 W'/CP 物理核算**。

## W'/CP 核算（CP=300W）

**每 cycle 高于 CP 消耗**：
- 90s @ 330W: (330-300)×90 = 2700J = 2.7 kJ
- 30s @ 500W: (500-300)×30 = 6000J = 6.0 kJ
- **每 cycle = 8.7 kJ**

**每 set 4 cycles = 34.8 kJ**
- ECP 模型 W' = 25.4 kJ ← 不够
- 5/8 KOM 实测 W' + AWC = 36 kJ ← 勉强够 1 set

**4 set 累积 = 140 kJ**
- W' 重建模型 (Skiba): 5min Z1 理论 99% 重建
- 实测重建率: 70-85%
- Set 1: 100% W' (25 kJ) → Set 2: 75% (19 kJ) → Set 3: 60% (15 kJ) → Set 4: 50% (12 kJ)
- 每 set 需要 35 kJ 而池内只有 12-25 kJ → **数学不允许**

## 实战预测

| Set | 进入 W' | 需要 | 完成度预测 |
|---|---|---|---|
| 1 | 25 kJ | 35 kJ | 第 4 cycle 冲刺从 500W 掉到 400W |
| 2 | 18-20 kJ | 35 kJ | 大概率 3 cycles 后停 |
| 3 | 12-15 kJ | 35 kJ | 只能完成 2 cycles |
| 4 | <10 kJ | 35 kJ | 完成不了，强行进糖酵解过载 |

**结论**：用户大概率踩完 2-2.5 set，第 3 set 崩，第 4 set 不可能。我设计的 150 TSS 实际上是"理论 4 set，实际做不完"。

## v6 vs 5/8 KOM 对比

| | 5/8 KOM 实战 | 5/10 v6 设计 |
|---|---|---|
| 总 hard work | 16min 连续 | 32min 分段 |
| W' 消耗 | 36 kJ (1 次榨干) | 35 kJ × 4 set 重启 |
| 累积要求 | 36 kJ | 140 kJ ← 物理不允许 |
| 冲刺 ≥450W 次数 | 0 | 16 次 @ 500W |
| 神经压力 | 中（持续） | 极高（16 次刺激） |

**比 KOM 还狠的 session 放在 race 周第 1 天 — 设计错误**。

## v6.1 修正方案 (5/10 改)

**3 set × 3 cycles × (90s @ 330W + 30s @ 450W)**

- 每 cycle = (330-300)×90 + (450-300)×30 = 2.7 + 4.5 = **7.2 kJ**
- 每 set 3 cycles = **21.6 kJ ← 在 W' 池内**
- 9 次 450W 冲刺仍训练 race 拉锯节奏
- ICU 实算 TSS = **92**（vs 错版 150）

## 元教训：第 6 种 sycophancy / 数学盲

之前已识别 5 种：
1. 顺着用户说
2. 用乐观估计给台阶下
3. "你在变好"叙事包装
4. 用均值代替常规
5. 用过时数据源

**第 6 种**：**不做物理核算就设计 session**。"看起来合理 + ICU TSS 计算 = 数字"，但 ICU 算的是 NP-based TSS，不是 W'/CP 可行性。**TSS 数字合理 ≠ 生理可行**。

## 新 HARD RULE（落 [[athlete]]）

所有 ≥110% FTP burst 间歇 session 设计前必做：
1. W'_per_cycle = (P_steady - CP) × t_steady + (P_burst - CP) × t_burst
2. W'_per_set ≤ 用户 W' 池（25-36 kJ）
3. n_sets 考虑 70-85% 实际重建率
4. 实战预测每 set 完成度

**违规 session 直接拒绝出版**。
