## 修正细节

### Rule 1: Mountain 2 OU 改 10min 高强度
- 原 4×12min @ 105/90% 不适合 Mountain 2（10-11min 爬不够 12min set）
- 改 **4×10min @ 110/90% 1/1 快循环**：
  - 5 cycles × (1min @ 330W + 1min @ 270W) = 10min ✓
  - 强度：110% > 105%（提升）
  - 节奏：1/1 > 2/2（更快 lactate cycling）
  - 与 Mountain 2 climb time 完美匹配

### Rule 2: 5/11 加训练
- 5/12 work 不变，5/11 用上 = Mountain 3 30/30
- 与 5/10 Mountain 2 (180 TSS) 背靠背 OK（5/10 < 200）

### Rule 3: chart 时间轴 fix
- v6.5 的 workout_text 含 75min Z2 commute → chart 渲染怪异
- v6.6 改 workout_text **只含工作组**（暖身 + 间歇 + cooldown at base）
- duration_min = workout_text 实际总时长（如 81 / 50 / 50）
- commute 在 description 解释
- ICU TSS calc 从 workout_text 得出 = 仅工作组 TSS（如 127 / 60 / 110）
- 真实 ride TSS 含 commute = ICU calc + ~80 TSS（25km 来回）
- **trade-off**：calendar TSS 看着低，但 chart 干净

### Rule 4: Mountain 3 加入
- 0.8km × 8.1%，25km bike out，人少
- 结构：陡-缓-陡-缓-陡（陡 ~15% / 缓 ~3%）
- **1 ascent = 3 reps natural 30/30**（terrain-driven，比计时器更真实）
- 4 ascents = 12 reps = 1 standard set
- 适合 30/30 / 30/15 / 40/20 / W' burner

## Mountain 3 价值

加入 Mountain 3 给 30/30 类训练添加 race-specific 选项：
- Trainer 30/30 = 节奏精确但不真实
- Local 平路 30/30 = 节奏 OK 但单调

未来所有 30/30 / 30/15 / 40/20 类 session 优先 Mountain 3 + bike commute。
