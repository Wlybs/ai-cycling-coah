## 🔍 关键观察

### 1. lap-based 系统性低估,完成度判定翻转
- 稳态: lap 切前缘 ramp-up (12-17s) → 偏低 6.3%
- spike: lap 窗口偏短没含完整 peak,但 avg 比 det avg 高(因为 det 窗口扩大把 tail 包进去)
- **看 spike 必须看 peak 不是看 avg**:`det_max` 才是冲刺能力真实指标
- 用 lap avg 判 → 5/9 达标 (中等)
- 用 det peak 判 → **9/9 达标 (明显 over-target)**

### 2. 踏频是 spike 输出的隐变量
- Set 1 spike 平均踏频 99 rpm → peak avg 576W
- Set 2 spike 平均踏频 106 rpm → peak avg 602W (**最高**)
- Set 3 spike 平均踏频 90 rpm (摇车) → peak avg 559W,有一个塌到 487W
- **race 中段拉锯如果选摇车,踏频 ≥ 95 rpm 是出 480W+ 输出的下限**

### 3. 主课 vs 主课外两次冲刺定位不同
- 主课 9 spike: peak avg **579W** / 15s 体 / 烧 W' 1-2 kJ 每次 → race 中段拉锯节奏训练
- Outbound 全力 1016W peak / 7s → neuromuscular (磷酸原系统,纯肌肉爆发)
- Return 全力 1019W peak / 21s / W' 烧 7.9 kJ → anaerobic capacity (烧 W' 池)
- **这两次主课外冲刺剂量比主课重得多**(W' 烧 7.9 kJ vs 主课 single spike 1-2 kJ),实际身体负荷比 TSS 124 显示的更高

### 4. race day implication
- 主课 9 spike 全部达 peak ≥ 480W,**race 起跑爆点段 / 中段拉锯 spike 动作能力交付**
- Return 长冲 1019W peak (21s) 说明 anaerobic capacity 仍然完好 → race 末段冲刺无问题
- Outbound 短爆 1016W peak (7s) 说明 neuromuscular 系统也完好 → race 起跑爆点没问题
- 整体 dose 评估: 稳态 over target 23W + spike peak over target 99W + 两次主课外全力冲刺 = **比 TSS 124 字面看到的更强的真实负荷**,但仍在 race-rhythm 训练剂量范围(W' 池每个动作都有回血窗口)
