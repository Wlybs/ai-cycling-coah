## 核心洞察

1. **4/25 名次好不是因为更强，是因为 W' 调度好**：两场 IF 都是 1.04-1.05（同等强度），4/25 留了 26% W' 缓冲 → 末段还有牌，结果 6th；3/28 W' 100% 烧光 → 19th。
2. **两场都有 2 次清晰攻击峰** in min 7 + min 17 区域（582-652W），符合"中段 2-3 次集团洗牌"模式。
3. **3/28 min 15-16 出现 2 分钟"战术夹缝"**（220-237W），地形给的喘息，但你 W' 已空没占到便宜。**这是免费午餐没吃**。
4. **HR 启动太快**：两场 min 1-2 HR 已经 184-186（≈LTHR 188）→ ceiling 烧太早，opener 不足或 warmup 不充分。
5. **20min PB 313W (3/21) ≈ 4/25 race avg 304W** — 地区单爬赛实际就是 **CP20 test + 战术叠加**。

## 推断的地区爬坡赛 4 段节奏

### Phase 1 (0-2min): 爆点起手
- 380-400W (1.27-1.33×FTP)，HR 165→190
- 抢前 5-10 名位，占据集团前部
- 失败成本：上坡无 draft，掉位 = game over

### Phase 2 (2-8min): 集团成型 + 稳态
- 300-345W (1.00-1.15×FTP)，HR 190→195
- 节奏由集团强者定，sit-in

### Phase 3 (mid-race): 拉锯 + 2-3 次攻击
- 290-340W 稳态，HR pegged 195+
- 嵌入 2-3 次 10-30s 冲刺 500-650W (1.7-2.2×FTP)
- 1-2 次"战术夹缝" 60-120s 220-260W
- 攻击通常发生在：坡度突变点 / 转弯出口 / 主集团碎裂时刻

### Phase 4 (last 2-3min): 末段决战
- 300-340W avg + 最后 30s 冲刺 500-600W
- 决名次关键段
- HR 顶 200+ 直至终点

**总 W' 预算 25-27kJ = 你 usable W' 的 100%**

## 对 [[training-plan]] 的验证

- **S1 火车拉扯（6min 内 30s on/off 反复）** 节奏 = 实测 Phase 3 的攻击模式 ✓
- **S2 集团生存（Over-Under）** = 实测 Phase 2 + Phase 3 的稳态+反复 ✓
- **S3 末段冲刺** = 实测 Phase 4 必要能力 ✓
- 训练 plan 设计**与实测比赛节奏吻合**

## 对 5/17 战术建议（具体）

- 赛前 25-30min 暖身：2×3min @ 105% FTP + 1×30s @ 150% FTP（开 anaerobic 通道）；**禁 Z1**
- Phase 1：1 分钟内 380-400W 抢前 5 位
- Phase 2：320-340W 跟车轮，**别拉风**
- Phase 3：识别 2 个攻击窗口 — 坡度突变 / 集团减速；每次 ≤30s @ 500W+
- **战术夹缝反向操作**：地形给的缓坡时 → 主动攻击（对手也在 W' 回血，时机对等但你抓时机）
- Phase 4：留 5-7kJ W' 给最后 60s；500m 内启动冲刺

## 触发器

- 5/17 课程 ≠ 20-26min（如 35min）→ Phase 3 延长，攻击 3-5 次
- 多段重复爬坡（非单爬）→ 4 段失效，改"间歇赛"模型
- 实战反馈"攻击只 10s" → S1 改 5/5s 短爆破
