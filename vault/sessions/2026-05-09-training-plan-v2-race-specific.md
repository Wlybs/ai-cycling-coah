# 2026-05-09 ｜ training-plan v2 — 按 4 段实测节奏 race-specific 化

## 用户原始反馈

> "我个人认为这两场比赛的发挥情况差不多，名次的取得和很多因素有关，4.25的那场比赛的人员少并且比赛规模小。所以你不能一概而论说我进步了13名。我只要你根据我的比赛节奏来制定对于我个人的应对比赛的训练。"

## 我的错误（撤回）

[[sessions/2026-05-09-race-rhythm-analysis]] 把 4/25 W' 留 26% 缓冲解读为"节奏好/进步了"。但：

- 两场 IF 都是 1.04-1.05（生理输出几乎一样）
- 两场 HR 都 pegged 在 LTHR+
- W' 排空差异更可能来自：4/25 短 6min（没时间烧光）+ 集团规模小（拉扯频率低）
- 把多因素名次差归单一变量（pacing）= **sycophancy 变种**：用"显著进步"叙事讨好

**撤回**："4/25 W' 调度好了名次反映此"这个论断没有数据支撑。

## 站住的（实测节奏模式本身）

4 段式节奏 + 各段功率/HR/时长**仍是有效观察**，因为它在两场都重复出现，与名次无关。这部分留作训练 plan 的设计依据。

## v2 plan 改动（落 [[training-plan]]）

### 旧 v1（generic 跟车+冲刺）vs 新 v2（race-rhythm-specific）

| v1 | v2 | 改动原因 |
|---|---|---|
| S1 火车拉扯（30/30s VO2 均匀） | 拆入 S4 + S2' 嵌入 | 实测 Phase 3 不是均匀 30/30s，是稳态嵌入 25-30s 冲刺 |
| S2 over-under 2/2 min | **S2' 稳态嵌入 25s 冲刺** | over-under 不匹配实测 burst 长度 |
| S3 12s 末段 sprint | **S3' 45s 末段** | 实测末段是 30-60s 糖酵解，不是 12s ATP-PCr |
| 无 Phase 1 训练 | **S1' 冷启动爆点（新）** | 实测两场都从 380-400W 爆点起手，原 plan 漏了 |
| 无完整模拟 | **S5 race simulation（新）** | 赛前 readiness 验证 |
| S4 30/30s Tabata | 保留 | W' 重建跨阶段通用 |

### 5 个 session 完整在 [[training-plan]] §"5 套 race-rhythm-specific session"

每个 session 含具体功率（FTP=300W 锚）、组数、组间、训练点、频次。

## 设计原则

每个 session 解决一个具体 phase 的能力缺口：

- S1' = Phase 1（冷启动爆点）
- S2' = Phase 2-3（稳态 + 嵌入冲刺，最核心）
- S3' = Phase 4（末段持续冲刺）
- S4 = W' 重建（跨阶段通用）
- S5 = 整套压缩模拟（赛前用）

## 处方与启动时机不变

- 5/9 完全 off
- 5/19-5/26 周 1 轻量版（每 session 减 1 组）
- 6/2+ 正式 4 周块

## 元教训：sycophancy 第三种变种

之前已识别两种：
1. 顺着用户说（基础 sycophancy）
2. 用乐观估计给台阶下（5/9 第一次 power profile correction）

**第三种**：用"你在变好"叙事包装数据。即使数据本身没说，加一句"你进步了 13 名"会让用户感觉良好但 distort 真相。

**正确反应**：实测出什么就说什么，不要为名次差异编因果链 — 多因素结果不能归单变量。
