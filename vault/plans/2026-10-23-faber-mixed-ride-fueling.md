# 10月23日17点｜Faber–Mandai–LCK混合课与全天吃法

## 今日结论
昨晚聚餐摄入未量化，今早64.9kg不能分拆成脂肪/糖原水/盐水/肠内容物，不断言全是水或全是脂肪。今天按实际食欲调整餐次，不为抵扣聚餐而延长空腹或削减4–5h训练供能。现在约09:30，不饿可先正常喝水，11点吃第一餐；饿了提前吃，不追空腹时长。后续按既定固定早晨称重看周平均，不以明天急降作为减脂成功。

## 骑行（4–5h是准备范围，非核实ETA）
| 顺序 | 执行 |
|---|---|
| 17点NTU→Faber | 最初10–15min轻松；往Faber本身就是热身/有氧，市区自然骑、畅顺185–205W，不另补30min热身 |
| Faber六趟 | 每趟整坡约280W，270–285路况自然波动；约5min只是估计，按熟悉终点记；正常下坡恢复，不压成1min、不做VO2/PR |
| Faber→Mandai→New Tiew→LCK | 作为有氧转场，畅顺185–205W；不抵LCK后另加100min，不把转场用时假定为恰100min |
| LCK主工作 | 3×10min首290、后295W；组间各5min实际轻松。整组后按本次实际累计负荷判断是否只加时或只加瓦，不预定升级；正常末组8–9稳定可完成，异常早段困难退5–10W/减组 |
| 回NTU | 自然轻松骑回、计入总量；预计21–22点附近返校仅按4–5h范围推算，非已核路线ETA |

自然踏频。Sat默认休，Sun按恢复决定Crazies是否参加与强度。未推ICU，不加额外质量内容。

## 打包（本人有2×550、2×600、2×720ml；今天选2×720）
| 物品 | 用量 / 配法 |
|---|---|
| 100PLUS Original | 约1.4L，分两只720ml壶；标签5g碳水/100ml |
| 白糖 | 共125g：起步两壶各25g=50g；另分25g×3包=75g，路上补水用 |
| 香蕉 | 1根，带皮100–150g的现有大小，碳水粗估15–20g，非实测果肉 |
| 无咖啡因胶 | 4支，选45g包装、40g碳水/支那款；5h计划3支、1支备用，4h通常2支。若用45g碳水/支款，按实际标签增加5g/支计入，不另叠加补齐 |

每只壶先倒约650ml已放气100PLUS，溶入25g糖，再补同款100PLUS到接近满、留混匀空间；实际原饮料约680–700ml/壶，每壶约59–60g碳水，数学账按约60g。不要把700ml饮料+25g糖误称最终700ml成品，也不为1–2g差异追补。
每包补水糖25g用约700ml清水冲，约25g碳水/壶；电解质组成不等同100PLUS。可选每包预混约0.5g普通食盐（额外约200mg钠/壶），属于一般低浓度便携配方，不是已测个人汗钠需要、不强制、不承诺防抽筋。100PLUS和胶钠标签未核，本次不虚构全程钠总量或宣称已经满足个体需求；不需要机械补盐片。

## 路上吃喝（以65–70g碳水/h左右执行，不要求每小时毫克级相同）
| 时段 / 阶段 | 怎么吃 |
|---|---|
| 17–19点前约2h | 糖饮分散小口喝；约17:40/到Faber前平路吃香蕉。初两壶约120g+香蕉15–20g，合计约135–140g/2h。别等饿了才开始 |
| 19–21点随后约2h | 在确认可补水处补满水壶，每壶约700ml清水+25g糖，共用两包=50g；约19:15、20:15各1支40g胶，分几口配水吃，合计约130g/2h。第二支可移到LCK主工作前10–20min，注意别与前一支紧挨后又重复吃 |
| 超过4h、继续到22点附近 | 第三包25g糖配清水+第三支40g胶（约21:15/第五小时），新增65g；已回校就不为清库存硬吃 |
| 第四支胶 | 仅延时、香蕉掉了或实际少喝糖液等机动；不是无条件每次吃完 |

按实际喝完相应糖液的前提：4h约265–270g，5h约330–335g；因壶容量和香蕉果肉存在差异仅为约数。没喝完就扣除实际剩余，不仍按满壶记。
饮水随口渴/出汗调整，不强迫按糖配方灌水。用于碳水换算：起步糖饮约8.5g/100ml，少半壶约少30g碳水；补水糖饮少一整壶约少25g。用胶按标签补这部分（40g一支可分几口补差），并保持每小时近65–70g；备用耗尽又明显缺补给时需补买碳水或下调后段任务，不一边少喝少吃一边照追原负荷。先前水壶尚有糖液时先计其剩余，补水不重复把同一糖量算两次。
初1.4L并非4–5h全部水。出发前确认Faber离开后、进入北段前的实际补水点；起步两壶接近用完前补满两壶，5h或汗多需再补清水。若按配方全部喝完约需4h2.8L/5h3.5L，这只是配方对应液量，不是测得个人汗率或硬性饮水量；今日未核店名/营业时间，不保证任一水点可用。
